2. 🧼 Clean Code Violations
- `org.geantlr.services.CustomErrorListener`: The `syntaxError` method is overly complex. Refactoring advice: Break down the logic into smaller, more readable methods. Add comments explaining the logic, especially around the error detection.
- `org.geantlr.services.PlantUmlParsingService`: `reader.getBlocks().get(0).getDiagram()` should use modernization methods (see below) and better error handling if the list is empty.

3. 📐 MVVM Violations
- `org.geantlr.viewmodels.MainViewModel`: Imports `org.geantlr.services.TokenHighlightMappingService` (though unused, it shouldn't be there as styling/CSS services belong strictly to the View layer).

4. 🚀 Static Analysis & Modernization
- `org.geantlr.services.PlantUmlParsingService`:
  `var diagram = reader.getBlocks().get(0).getDiagram();` -> `var diagram = reader.getBlocks().getFirst().getDiagram();`
- `org.geantlr.views.MainViewController`:
  `saveEditorContent(viewModel.getActiveEditors().get(0));` -> `saveEditorContent(viewModel.getActiveEditors().getFirst());`
  `choices.put("Left Editor", viewModel.getActiveEditors().get(0));` -> `choices.put("Left Editor", viewModel.getActiveEditors().getFirst());`

5. 📦 Dependency Audit (pom.xml)
- `junit-jupiter-api`: Update from `5.10.1` to the latest `5.10.x` or `5.11.x` version for better stability.
- `mockito-core`: Update from `5.11.0` to the latest `5.x.x` if available.
- `jacoco-maven-plugin`: Version `0.8.12` is specified but skipped by default due to Java 25. Consider checking for newer milestones that support Java 25.

🏛️ Kay's Final Verdict
The codebase demonstrates a solid structural foundation but is currently marred by a significant lack of unit test coverage across critical view models and core domain services. There are minor Clean Code and MVVM infractions, notably the leaked UI styling service into `MainViewModel` and unused code clutter. Modernizing list access methods to utilize Java 21+ `.getFirst()` and strictly enforcing the separation of concerns will bring the application closer to modern architectural standards.
